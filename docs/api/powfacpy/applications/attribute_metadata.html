powfacpy.applications.attribute_metadata

Work with PowerFactory attributes through the names shown in the GUI.

PowerFactory stores every attribute under a terse code (pgini, i_mot, iexchange) and many attributes are enumerations whose value is an opaque integer (ElmSym.i_mot is 0 / 1 / 2 for Generator / Motor / Condenser). AttributeMetadata bridges that gap:

  • set_enum / set_attributes - write an enumeration by the option name shown in the dialog (machine.i_mot = "Motor"), not the integer;
  • enum_options / enum_name / enum_code - list an enumeration's options and translate between code and name;
  • label - the GUI label of an attribute (ElmSym / pgini -> "Dispatch");
  • describe - a small table of an object's attributes with labels and decoded values.

The same enum-name translation is available directly on ActiveProject.set_attr(obj, params, resolve_enum_names=True).

Where the names come from: PowerFactory ships a SQLite database of every GUI string (<install>/localisation/en-GB/data.db, one table Message(lang, class, param, message) - the same file DigsilentLibrary uses for folder names). Enum options are resolved from, in order: the live attribute description (obj.GetAttributeDescription / app.GetAttributeDescription), the same string in that database, then the database's <attr>_<code> option rows. The database is needed only for that last source - PowerFactory's API returns inline option lists (ElmVsc.i_acdc -> "Control mode:Vac-phi:Vdc-phi:...") but just the label for many enums (i_mot, i_net, imode, ...). If the database cannot be read, those fall back to "options unknown" (one warning) and everything else keeps working.

Scope: this covers integer-coded enumerations. String-coded ones (ElmSym.av_mode = "vdroop", ElmGenstat.mode_inp = "PQ") already read and write as their string, so enum_options returns {} for them and set_attributes passes the string through unchanged. A few enums (iexchange) have their options in neither the API nor the database and also return {} - pass the integer code for those.

 58#: `param` of an option row: ``<attr>_<code>`` (e.g. ``i_mot_2``).
 59_OPTION_ROW = re.compile(r"^(?P<attr>.+)_(?P<code>\d+)$")
 60#: an inline option carrying an explicit code, e.g. ``&2&isolated``.
 61_EXPLICIT_CODE = re.compile(r"^&(?P<code>\d+)&(?P<label>.*)$")
 62

 64@lru_cache(maxsize=4)
 65def _read_localisation_db(path: str) -> dict[tuple[str, str], str]:
 66    """`{(class, param): message}` for the English rows of a localisation database.
 67
 68    Cached on the path string. Raises `OSError` / `sqlite3.Error` on failure; the
 69    caller decides whether to warn and fall back.
 70    """
 71    with sqlite3.connect(f"file:{path}?mode=ro", uri=True) as connection:
 72        rows = connection.execute(
 73            "SELECT class, param, message FROM Message WHERE lang = 'en'"
 74        ).fetchall()
 75    return {(class_name, param): message for class_name, param, message in rows}

 78def _strip_marker(text: str) -> str:
 79    """Drop PowerFactory's leading ``~`` (translatable-string marker) and trailing
 80    ``|<abbreviation>`` (column-header short form)."""
 81    text = text.strip()
 82    if text.startswith("~"):
 83        text = text[1:]
 84    return text.split("|", 1)[0].strip()

 87def _parse_inline_options(description: str | None) -> dict[int, str]:
 88    """Parse ``"Label:opt0:opt1:..."`` (optionally ``"...:&2&opt:&5&opt"``).
 89
 90    Returns ``{}`` unless the string has at least two colon-separated option
 91    segments that look like enum entries (short, no sentence punctuation), so a
 92    prose description that happens to contain a colon is not misread.
 93    """
 94    if not description or ":" not in description:
 95        return {}
 96    label, *raw_options = description.split(":")
 97    if len(raw_options) < 2:
 98        return {}
 99    # the last option may carry the label's trailing "|abbreviation"
100    raw_options[-1] = raw_options[-1].split("|", 1)[0]
101    raw_options = [option.strip() for option in raw_options if option.strip()]
102
103    explicit = [_EXPLICIT_CODE.match(option) for option in raw_options]
104    if all(explicit):
105        return {
106            int(match.group("code")): _strip_marker(match.group("label"))
107            for match in explicit
108        }
109    if any(explicit):  # mixed - malformed, don't guess
110        return {}
111    if any(len(option) > 40 or option.endswith((".", "!")) for option in raw_options):
112        return {}  # looks like prose, not an enum
113    return {index: _strip_marker(option) for index, option in enumerate(raw_options)}

121class AttributeMetadata(ApplicationBase):
122    """Read and write PowerFactory attributes by their GUI names.
123
124    Example:
125        ```python
126        meta = AttributeMetadata(app)
127
128        meta.set_enum(machine, "i_mot", "Motor")          # machine.i_mot = 1
129        meta.set_attributes(controller, {"i_net": "Power-Frequency Control", "psetp": 0.0})
130
131        meta.enum_options("ElmSym", "i_mot")              # {0: 'Generator', 1: 'Motor', 2: 'Condenser'}
132        meta.enum_name(machine, "i_mot", 1)               # 'Motor'
133        meta.enum_code("ElmSecctrl", "i_net", "Power-Frequency Control")  # 1
134
135        meta.label("ElmSym", "pgini")                     # 'Dispatch'
136        meta.describe(machine, ["i_mot", "pgini"])        # a small DataFrame
137        ```
138
139    Every lookup accepts either a PowerFactory object (uses its class and its live
140    `GetAttributeDescription`) or a class name string (uses
141    `app.GetAttributeDescription`).
142    """
143
144    def __init__(
145        self, pf_app: PFApp | None | bool = False, cached: bool = False
146    ) -> None:
147        super().__init__(pf_app, cached)
148        self._db_unavailable_warned = False
149
150    # ---- database ------------------------------------------------------- #
151    @cached_property
152    def localisation_db_path(self) -> Path:
153        """Path of PowerFactory's English GUI-string database."""
154        return (
155            Path(self.app.GetInstallationDirectory())
156            / "localisation"
157            / "en-GB"
158            / "data.db"
159        )
160
161    @property
162    def _db(self) -> dict[tuple[str, str], str]:
163        """The localisation table as `{(class, param): message}`, or `{}` if it
164        cannot be read (warns once)."""
165        try:
166            return _read_localisation_db(str(self.localisation_db_path))
167        except (OSError, sqlite3.Error) as error:
168            if not self._db_unavailable_warned:
169                warn(
170                    f"Could not read the PowerFactory GUI-string database at "
171                    f"'{self.localisation_db_path}' ({error}); enum options that are "
172                    f"not in the live attribute description are unavailable.",
173                    RuntimeWarning,
174                )
175                self._db_unavailable_warned = True
176            return {}
177
178    # ---- labels ------------------------------------------------------- #
179    def label(
180        self, obj_or_class: PFGeneral | str, attr: str, *, short: bool = False
181    ) -> str | None:
182        """The GUI label of an attribute (e.g. `ElmSym` / `pgini` -> "Dispatch").
183
184        `short=True` returns the abbreviated column-header form where one exists.
185        Returns `None` if the attribute has no known label.
186        """
187        description = self._description(obj_or_class, attr, short=short)
188        if description is None:
189            class_name = self._class_name(obj_or_class)
190            description = self._db.get((class_name, attr))
191        if not description:
192            return None
193        # drop any inline option list; the label may still carry "~" and "|abbrev"
194        full = description.partition(":")[0].lstrip("~")
195        if "|" in full:
196            long_form, short_form = full.split("|", 1)
197            return short_form.strip() if short else long_form.strip()
198        return full.strip()
199
200    # ---- enums ------------------------------------------------------- #
201    def enum_options(
202        self, obj_or_class: PFGeneral | str, attr: str
203    ) -> dict[int, str]:
204        """`{code: name}` for an enumeration attribute, or `{}` if the attribute is
205        not a known integer-coded enumeration.
206
207        Merges the live/API description, the same string in the database, and the
208        database's `<attr>_<code>` option rows (used only when `<attr>_0` exists
209        and the codes run contiguously from 0).
210        """
211        class_name = self._class_name(obj_or_class)
212
213        for description in (
214            self._description(obj_or_class, attr),
215            self._db.get((class_name, attr)),
216        ):
217            options = _parse_inline_options(description)
218            if options:
219                return options
220
221        return self._option_rows(class_name, attr)
222
223    def enum_name(
224        self, obj_or_class: PFGeneral | str, attr: str, code: int
225    ) -> str:
226        """The option name for an integer `code`. Falls back to `str(code)` if the
227        options are unknown; raises `PFEnumValueError` if they are known but do not
228        contain `code`."""
229        options = self.enum_options(obj_or_class, attr)
230        if not options:
231            return str(code)
232        try:
233            return options[int(code)]
234        except (KeyError, ValueError):
235            raise PFEnumValueError(
236                self._class_name(obj_or_class), attr, code, options
237            )
238
239    def enum_code(
240        self, obj_or_class: PFGeneral | str, attr: str, value: int | str
241    ) -> int:
242        """The integer code for an option `value` (its name, or an int / numeric
243        string passed straight through).
244
245        Names match case-insensitively and ignore a leading `~`. Raises
246        `PFEnumValueError` if `value` is a string that is not one of the options
247        (and the options are known)."""
248        if isinstance(value, int):
249            return value
250        text = str(value).strip()
251        if text.lstrip("-").isdigit():
252            return int(text)
253        options = self.enum_options(obj_or_class, attr)
254        wanted = text.lstrip("~").casefold()
255        for code, name in options.items():
256            if name.casefold() == wanted:
257                return code
258        if not options:
259            raise PFEnumValueError(
260                self._class_name(obj_or_class),
261                attr,
262                f"{value} (no option names known for this attribute - pass the "
263                f"integer code)",
264                options,
265            )
266        raise PFEnumValueError(self._class_name(obj_or_class), attr, value, options)
267
268    # ---- writing --------------------------------------------------- #
269    def set_enum(
270        self, obj: PFGeneral, attr: str, value: int | str
271    ) -> None:
272        """`SetAttribute(attr, ...)` with `value` given as an option name or code."""
273        obj.SetAttribute(attr, self.enum_code(obj, attr, value))

275    def set_attributes(
276        self,
277        obj: PFGeneral | str,
278        params: dict,
279        parent_folder: PFGeneral | str | None = None,
280    ) -> None:
281        """Like `ActiveProject.set_attr`, but a string value for an enumeration
282        attribute is translated to its integer code first.
283
284        A string value whose attribute is not a known enumeration is written
285        unchanged, so this is a safe drop-in. `ActiveProject.set_attr(obj, params,
286        resolve_enum_names=True)` does the same thing.
287        """
288        obj = self.act_prj._handle_single_pf_object_or_path_input(
289            obj, parent_folder=parent_folder
290        )
291        self.act_prj.set_attr(obj, self.resolve_enum_names(obj, params))
292
293    def resolve_enum_names(self, obj: PFGeneral, params: dict) -> dict:
294        """Return `params` with every string value that names an enumeration option
295        replaced by its integer code (other values untouched).
296
297        Used by `set_attributes` and by `ActiveProject.set_attr(...,
298        resolve_enum_names=True)`.
299        """
300        resolved = {}
301        for attr, value in params.items():
302            if isinstance(value, str) and self.enum_options(obj, attr):
303                resolved[attr] = self.enum_code(obj, attr, value)
304            else:
305                resolved[attr] = value
306        return resolved
307
308    # ---- describe ------------------------------------------------- #
309    def describe(
310        self, obj: PFGeneral, attrs: list[str]
311    ) -> pd.DataFrame:
312        """A table (`attr` index) with the GUI `label`, the raw `value`, and the
313        decoded `enum_name` (``None`` for non-enum attributes) of each attribute.
314
315        Handy for an at-a-glance look at an object in a notebook.
316        """
317        attrs = list(attrs)
318        labels, values, names = [], [], []
319        for attr in attrs:
320            value = obj.GetAttribute(attr)
321            options = self.enum_options(obj, attr)
322            name = None
323            if options and isinstance(value, (int, float)):
324                value = int(value)  # enum codes come back as float from the API
325                name = options.get(value)
326            labels.append(self.label(obj, attr))
327            values.append(value)
328            names.append(name)
329        return pd.DataFrame(
330            {
331                "label": labels,
332                "value": pd.Series(values, index=attrs, dtype=object),
333                "enum_name": names,
334            },
335            index=attrs,
336        )

338    # ---- internals ------------------------------------------------- #
339    def _class_name(self, obj_or_class: PFGeneral | str) -> str:
340        return (
341            obj_or_class
342            if isinstance(obj_or_class, str)
343            else obj_or_class.GetClassName()
344        )

346    def _description(
347        self, obj_or_class: PFGeneral | str, attr: str, *, short: bool = False
348    ) -> str | None:
349        """The live attribute description, from the object or `app`, or `None`."""
350        flag = 1 if short else 0
351        try:
352            if isinstance(obj_or_class, str):
353                description = self.app.GetAttributeDescription(
354                    obj_or_class, attr, flag
355                )
356            else:
357                description = obj_or_class.GetAttributeDescription(attr, flag)
358        except (AttributeError, RuntimeError, TypeError):
359            return None
360        return description or None
361
362    def _option_rows(self, class_name: str, attr: str) -> dict[int, str]:
363        """Enum options from the database's ``<attr>_<code>`` rows.
364
365        Only used when the base ``<attr>`` row exists without inline options and
366        the codes run contiguously from 0 (so result-variable siblings such as
367        ``loading_1`` / ``loading_2`` are not mistaken for enum options).
368        """
369        database = self._db
370        if not database or (class_name, attr) not in database:
371            return {}
372        if ":" in (database.get((class_name, attr)) or ""):
373            return {}
374        options: dict[int, str] = {}
375        for (row_class, param), message in database.items():
376            if row_class != class_name:
377                continue
378            match = _OPTION_ROW.match(param)
379            if match and match.group("attr") == attr:
380                options[int(match.group("code"))] = _strip_marker(message)
381        if not options or set(options) != set(range(len(options))):
382            return {}
383        return options

363    def _option_rows(self, class_name: str, attr: str) -> dict[int, str]:
364        """Enum options from the database's ``<attr>_<code>`` rows.
365
366        Only used when the base ``<attr>`` row exists without inline options and
367        the codes run contiguously from 0 (so result-variable siblings such as
368        ``loading_1`` / ``loading_2`` are not mistaken for enum options).
369        """
370        database = self._db
371        if not database or (class_name, attr) not in database:
372            return {}
373        if ":" in (database.get((class_name, attr)) or ""):
374            return {}
375        options: dict[int, str] = {}
376        for (row_class, param), message in database.items():
377            if row_class != class_name:
378                continue
379            match = _OPTION_ROW.match(param)
380            if match and match.group("attr") == attr:
381                options[int(match.group("code"))] = _strip_marker(message)
382        if not options or set(options) != set(range(len(options))):
383            return {}
384        return options

def enum_code( self, obj_or_class: powfacpy.pf_classes.protocols.PFGeneral | str, attr: str, value: int | str) -> int: 
240    def enum_code(
241        self, obj_or_class: PFGeneral | str, attr: str, value: int | str
242    ) -> int:
243        """The integer code for an option `value` (its name, or an int / numeric
244        string passed straight through).
245
246        Names match case-insensitively and ignore a leading `~`. Raises
247        `PFEnumValueError` if `value` is a string that is not one of the options
248        (and the options are known)."""
249        if isinstance(value, int):
250            return value
251        text = str(value).strip()
252        if text.lstrip("-").isdigit():
253            return int(text)
254        options = self.enum_options(obj_or_class, attr)
255        wanted = text.lstrip("~").casefold()
256        for code, name in options.items():
257            if name.casefold() == wanted:
258                return code
259        if not options:
260            raise PFEnumValueError(
261                self._class_name(obj_or_class),
262                attr,
263                f"{value} (no option names known for this attribute - pass the "
264                f"integer code)",
265                options,
266            )
267        raise PFEnumValueError(self._class_name(obj_or_class), attr, value, options)
